# 下一版训练方案：局部遮挡鲁棒性

当前状态：**方案准备，尚未接入生产训练、未开训、没有新模型成绩。** 本轮只安排一个候选训练与必要确认评测，从已经完成百集全量的v3 4k raw继续。

## 目标与基线

v3完整本地评测已于2026-10-18 12:40（北京时间）结束：clean/seen **78.04%**、randomized/unseen **47.38%**、双场均分 **62.71%**，共10000集。旧十集均分65.60%，百集下修2.89个百分点；两次重新执行，不是严格逐集配对。

50个任务中，33个在clean达到80%以上，这些任务贡献1502/2631（57.09%）的randomized失败。下一版针对局部视觉信息缺失时的稳定性，促使策略结合其他相机与机器人状态完成动作；环境和语言同时变化，不能将全部差距归因为视觉。

## 唯一候选的设计

| 项目 | 本轮安排 |
| --- | --- |
| 父权重 | v3 · global_step_4000 · raw；weights-only建立新阶段 |
| 数据 | 官方Aloha-AgileX 50任务×50条clean演示，沿用已有seen语义绑定 |
| 新增改动 | 低概率局部Random Erasing，每个样本最多影响一路相机 |
| 初始遮挡参数 | 10%样本启用；选中视角单块面积2%–5%；其余视角保留 |
| 时间一致性 | 同一相机的当前帧和未来帧复用遮挡位置与大小 |
| 学生与教师 | 学生读取新增遮挡图；冻结教师读取新增遮挡之前、现有c2r增强之后的图像 |
| 已有训练配方 | 保留c2r、关节状态噪声、BC动作真值、原生深度/视频辅助监督、Muon及global1024 |
| 统计与推理 | 沿用父权重实际配套统计；FP32、chunk50/exec30、10步去噪、compile |
| 训练预算 | 单个候选2000–3000步预算；完成接入与吞吐检查后固定最终步数及低学习率日程 |
| 算力 | 默认本机最多4卡；启动前核对实际占用，训练与评测串行 |
| 确认顺序 | randomized/unseen 50×10 → clean/seen 50×10；值得升级时再跑新权重百集 |

这些遮挡参数是可审核的初始提案，尚未通过我方闭环验证。当前不叠加裁剪/平移/缩放、整主视角置零、RTC或额外模型；不做多概率网格和普通续训对照组。

本次分流不同于旧teacher_clean_rgb开关：教师保留现有c2r输入，只不接收新增擦除。这样保持空间位置与原有辅助目标对应，也避免把新增擦除传给教师后再将效果全部归因于学生鲁棒性。

## 输入与实现要求

依据[赛事规则§2.1.1](https://tianchi.aliyun.com/forum/post/1081761)，Random Erasing按训练期像素遮挡实施；保留clean动作标签和seen语义，不生成新轨迹，不调用仿真生成训练数据。教师按原生冻结感知辅助监督方式使用，推理仍是一份权重。

实现检查包括：

1. 从真实clean样本确认擦除范围、像素值域和相机次序，保留可复现的参数记录。
2. 检查训练开启/评测关闭、未命中样本直通，以及动作标签、指令和补齐维度保持原义。
3. 检查当前/未来帧重放和学生/教师输入分流，避免共享张量被原地修改。
4. 验证实际DataLoader/collator、随机状态保存恢复、checkpoint导出与重载。
5. 对已有FPS字段传递和flow随机流检查项分别完成语义核对。若修复进入本候选，记录具体变化与验证结果；不另开训练组，也不把组合收益全部归因于遮挡。

局部擦除是依据风险和工程约束选择的迁移方案，不能预填提升几个百分点。MaskVLA当前代码默认将primary整组通道清零，10%指启用概率，不是遮挡10%面积；本候选采用的局部擦除与之不同。

## 评测与采用标准

- 完成接入检查后固定一份训练配置，只训练一个候选，最终仅选一份权重进入确认。
- 首先完成全部50任务randomized/unseen十集；按多任务改善和实际计数判断是否值得继续clean确认，不能只看训练loss或少数成功case。
- 十集候选与v3十集记录按同口径比较，并披露两轮非严格逐集配对；不直接用十集候选减百集62.71称精确增益。
- 完整双场确认有改善后，再安排新权重的百集评测；保留v3作为已有完整结果的回退。
- 训练、评测结果、权重和正式01–04材料保持对应。现有真机Demo继续使用，仿真视频补录不在当前计划内。

## 时间预算

按已有四卡约23秒/step，2000–3000步纯训练约13–19小时，十集双场确认约8–12小时，新百集约85小时；另留加载、保存、接入与异常处理余量。10月18–19日定稿并启动的候选，按该速度预计10月23–24日收齐新全量；最终以实际启动时间和吞吐更新，不把估算写成已完成。
