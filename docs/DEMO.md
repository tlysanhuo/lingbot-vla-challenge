# 双臂字母块排列演示

[观看视频](../assets/demo/demo.mp4)

语言条件化双臂桌面操作：根据单词指令依次抓取、排列字母块，示例目标为“books”。观测包括顶视和左右腕部RGB。视频为同一次执行的三机位合成，完整时长约133秒；顶视原始录制较短，尾段为末帧保持。

仓库提供完整时序的压缩预览，未加速、未删减失败片段以改变展示含义。此演示及其独立真机数据不计入RoboTwin clean2500训练或确认分数。

现有项目记录描述了1000条、26个单词的独立真机演示和20k步微调；对应训练日志/权重未随本次代码发布，因此这里展示视频与既有记录，不将其作为额外可复算的定量实验。
